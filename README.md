You can find the demo notebook in `src/openfe-demo.py`.

See the [openfe git repo](https://github.com/OpenFreeEnergy/openfe) and [documentation](https://docs.openfree.energy/en/latest/) to learn more!

## Installing openfe locally

To run the notebook locally, you'll need to install [pixi](https://pixi.prefix.dev/latest/installation/), then run:


```bash

pixi run marimo edit openfe-demo.py

```

to run an editable marimo notebook.
